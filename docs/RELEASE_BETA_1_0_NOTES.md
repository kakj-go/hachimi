## Hachimi beta-1.0

这是一个面向 Windows 10/11 x64 的 Beta 预发行版，包含当前统一 Agent Runtime、项目工作区、浏览器与桌面控制、Skills、MCP、定时任务、平台集成、3D 桌宠和本地语音能力。

### Windows 下载

- `Hachimi_1.0.0_x64_en-US.msi`：Windows MSI 安装程序
- `Hachimi_1.0.0_x64-setup.exe`：Windows NSIS 安装程序

macOS 和 Linux 暂不支持，当前没有对应安装包。

### 发布说明

- Windows 二进制目前未进行代码签名，安装时系统可能显示安全提示。
- 这是 Beta 版本，真实外部服务、企业组织和特定 Windows 身份环境的验证状态以仓库发布 Gate 文档为准。
- 官方包包含默认 VRM，其许可禁止个人及企业商业使用，因此官方安装包仅用于非商业场景。Hachimi 源代码仍采用 Apache-2.0；商业发行前需要替换默认模型或另行取得授权。
