设计说明 · 二次元五套

五套共享同一 DOM 与信息架构，差异 100% 由 CSS 实现（含字体、形状语言、装饰、动效）。

像素物语（PC-98 / galgame）

  • 零圆角 + 硬阴影：所有卡片 2–3px 深色描边 + 4px 偏移实色阴影，按钮按下有位移反馈。
  • 扫描线 + 点阵底纹：全局 CRT 扫描线叠加，主区 18px 点阵。
  • Press Start 2P 数字字体：统计数字、耗时、路径、badge 全部像素字体。
  • 闪烁元素：未读点方块化并 steps() 闪烁，Composer 右下角有 ▼ 继续符（galgame 对话框梗）。
  • 顶栏装饰文案「★ PLAYER: MY_CODEX HP 98%」，强化游戏感。

奶油手帐（日系软萌）

  • 大圆角 + 奶粉色波点底：卡片 20–26px 圆角，背景樱花波点。
  • 和纸胶带：Composer 顶部和设置卡右上角有斜贴胶带装饰。
  • 贴纸化交互：建议胶囊虚线描边、hover 微旋转上浮；统计卡故意轻微旋转，像手贴便签。
  • ZCOOL KuaiLe 标题字体：中文手写感标题，正文仍用黑体保证可读性。
  • 装饰符号 ♪ ✦ ✿ ❀ ♡ 点缀标题，顶栏「きょうも がんばろう」。

黑猫夜行（暗夜黑猫）

  • 暖黑 + 琥珀瞳：底色是带棕调的暖黑 #161110，强调色用猫眼琥珀金 #FFB64D，选中态带微光。
  • 猫耳：首页 logo 和 Composer 顶部长出两只三角猫耳（clip-path 伪元素）。
  • 爪印底纹：背景用多层 radial-gradient 拼出重复爪印图案。
  • 装饰文案「ฅ^•ﻌ•^ฅ 夜行模式 · 黑猫值守中」，小节标题带 🐾。

橘猫咖啡（暖橘虎斑）

  • 虎斑条纹缎带：每张卡片、Composer、审批卡顶部趴着一条橘猫条纹带（repeating-linear-gradient）。
  • 咖啡馆暖调：奶油底 #FFF4E6 + 焦糖橙 #FF8C2E，分隔线用手帐虚线。
  • logo 也是虎斑纹，小节标题带 🐟，顶栏「☕ 橘猫咖啡馆 · 营业中」。
  • 贴纸胶囊、微上浮 hover，与奶油手帐同为暖系但更「猫」。

魔法星辰（魔法少女系）

  • 梦幻三色渐变：粉 → 薰衣草 → 天空蓝整页渐变 + 闪烁星星背景。
  • 彩虹缎带：卡片与 Composer 顶部一条五色渐变缎带；标题文字本身也是粉紫渐变。
  • 毛玻璃面板：侧栏与 Inspector 半透明 + backdrop blur，像浮在天空上。
  • Composer 右上角别着 🎀，logo 带 ✦ 闪光，顶栏「✧ MAGICAL LINK · 魔法连接中 ✧」。

落地注意

  • 五套都只改 CSS 令牌 + 覆盖层，不动组件 DOM 结构，可作为「主题包」挂进现有主题系统。
  • 像素方案的扫描线用 mix-blend-mode，魔法星辰用 backdrop blur，低端机建议提供降级开关。
  • Google Fonts 需联网加载，生产环境应本地化字体文件。
