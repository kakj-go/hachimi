设计说明

三套方案共享同一信息架构，差异在视觉语言与交互密度。

通用优化点（三套共有）

  • 会话状态条：选中会话用左侧 3px 强调色条 + 底色双重指示，替代原来仅靠浅底色的弱选中态。
  • 状态槽位归一：运行中 spinner、未读点、置顶、失败红点统一收进会话行右侧槽位，尺寸与颜色语义固定。
  • 审批内联化：审批从覆盖式弹层改为时间线内嵌卡片，带强调色描边光晕，拒绝 / 始终允许 / 允许一次三档操作平铺。
  • 工具批次可折叠：完成态默认折叠为一行摘要（含耗时），点击展开子项与路径。
  • 变更条可视化：文件变更行增加 +/− 数量与迷你比例条，一眼看出改动规模。
  • 设置页三层结构：PageHeading（标题+描述+badge）→ Section（小标题+说明）→ Card+Row，替代原来标题直接堆卡片。

方案 A · 石墨进化

  • 沿用现有 Quiet Graphite 深色（#111316 / #7062D5），修正侧栏紫渐变与内容区的色温割裂，整体统一到中性石墨灰。
  • 圆角、阴影全部收敛到 4 档令牌；信息密度保持现状，改动成本最低、可平滑落地。

方案 B · 纸雾浅白

  • 暖纸色背景（#F5F4F0）+ 纯白浮起卡片，强调色改为更沉稳的靛蓝 #4358C5。
  • 侧栏取消渐变、改用同色系米灰，靠白色浮起块表达选中，更接近纸面工具的安静感。
  • 适合长时间阅读 diff 与文档的场景；与深色方案共享全部令牌结构。

方案 C · 曜夜玻璃

  • 极深底色（#08090D）+ 全局面板毛玻璃（blur 20px + saturate），背景叠加淡紫色环境光晕。
  • 圆角整体 +2~4px、阴影更深，Composer 与审批卡带强调色辉光，强调「悬浮在桌面上」的空间层次。
  • 与桌宠透明窗的视觉语言最统一；代价是 backdrop-filter 在低端机上有性能开销。

交互细节演示

  • 设置页的开关、滑杆、密度分段、主题卡选中均可实际操作；「复制 JSON」会触发右下角 Toast。
  • 会话页工具批次可点击折叠 / 展开。
  • Composer 聚焦时边框过渡到强调色；发送按钮 hover 微放大。
