# Gitee Pull Requests API v5 contract snapshot

Retrieved: 2026-07-30T20:10:00+08:00

Official documentation checked with HTTP 200:

- API v5 Swagger: https://gitee.com/api/v5/swagger

Wire contract fixed for this implementation:

- `POST /repos/{owner}/{repo}/pulls` creates a PR with title/body and head/base refs.
- `GET /repos/{owner}/{repo}/pulls/{number}` returns PR state, refs, head SHA, URL, and update fields used for reconciliation.
- `PATCH /repos/{owner}/{repo}/pulls/{number}` updates title/body/base or closes with `state=closed`; the head ref remains the creation-time source.
- `PUT /repos/{owner}/{repo}/pulls/{number}/merge` performs a merge with the expected head SHA and optional merge title/message.
- Requests use token authentication and JSON responses.

Comments, review actions, labels, assignments, tests, and branch deletion are outside this snapshot.
