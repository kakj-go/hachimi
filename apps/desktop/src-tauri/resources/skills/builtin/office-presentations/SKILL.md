# Office presentations

Use structured presentation and media tools. This Skill provides design and verification guidance only; it cannot grant access or approve publishing.

1. Establish audience, purpose, duration, slide count, narrative, brand constraints, aspect ratio, and delivery format.
2. Build a clear sequence: context, evidence, decision or recommendation, next actions. Give each slide one primary message.
3. Use layouts and masters consistently. Prefer editable text, tables, charts, and diagrams over flattened screenshots.
4. Keep text concise and legible. Preserve source citations, alt text, speaker notes, and data provenance.
5. For revisions, retain unaffected layouts and objects. Summarize structural and content changes separately.
6. Render every slide and inspect overflow, overlap, clipping, contrast, fonts, image quality, chart labels, notes, and transitions that matter to delivery.
7. Export only requested formats and retain the editable source. Verify that PDF or image exports match the slide render.
8. Return controlled Artifact references, a slide-level change summary, and validation evidence.

If a render or export fails, keep the last valid deck and correct only the affected slides. Sharing or presenting through an external service requires current exact authority.

Read [validation.md](references/validation.md) before finalizing a deck.
