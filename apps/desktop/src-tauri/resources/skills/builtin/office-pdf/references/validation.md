# PDF validation

- Verify the file parses and the expected page count and dimensions are present.
- Render every changed page and inspect fonts, clipping, transparency, images, annotations, and form appearances.
- Extract text after edits; for redaction, search for removed values and inspect embedded objects and attachments.
- Record encryption, conformance, and signature changes.
- Keep original, derived PDF, page previews, and validation Artifact IDs distinct.
