# Document validation

- Verify the output opens with the format reported by the tool.
- Render every page and inspect page count, overflow, blank pages, headers, footers, tables, figures, and font substitution.
- Check required headings, links, references, metadata, and accessible reading order when applicable.
- For edits, compare the rendered result and structured change set with the source.
- Keep source, preview, export, and validation Artifact IDs distinct.
